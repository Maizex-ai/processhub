# .ide-preview — превью Markdown для ProcessHub

Здесь живёт **собственное расширение Cursor** `ProcessHub Markdown Preview`
(папка `extension/`) и скрипты его установки. Расширение оформляет **встроенное**
превью Markdown (`Ctrl+Shift+V`): панель свойств из YAML-шапки, тёмные диаграммы
PlantUML/Mermaid с кнопкой «раскрыть» и модальным зумом, карточка оглавления,
стилизованные таблицы, ссылки-чипы на документы.

Раньше всё это работало через Markdown Preview Enhanced (MPE) и файлы
`~/.crossnote` — та схема оставлена в папке `crossnote/` как архив, но больше
не используется и не обязательна к установке.

## Для команды: установка (Windows)

1. Получи папку `.ide-preview` (из репозитория или архивом).
2. Двойной клик по **`setup.cmd`**.
3. Перезапусти Cursor, открой `.md`-файл, нажми `Ctrl+Shift+V`.

Что делает `setup.cmd` (через `setup.ps1`):

- собирает пакет `*.vsix` из `extension/` (скрипт `build-vsix.ps1`, без сторонних
  инструментов);
- ставит его **штатной** командой `cursor --install-extension пакет.vsix` — это
  официальный механизм Cursor: реестр расширений и чужие расширения не трогаются,
  профиль пользователя не ломается;
- аккуратно дописывает в личный `settings.json` один ключ
  (`"markdown.preview.frontMatter": "show"`) — остальные настройки не трогает;
- добавляет `Ctrl+Shift+V` → встроенное превью (старый биндинг MPE убирает);
- всё, что меняет, предварительно бэкапит (`….bak-<timestamp>`).

Если `cursor` CLI нет в PATH — скрипт соберёт `.vsix` и подскажет поставить его
вручную: `Ctrl+Shift+P` → **Extensions: Install from VSIX…**

## Обновление расширения

Поправил `extension/extension.js` или `extension/media/*`:

1. подними `version` в `extension/package.json` (например `0.1.0` → `0.1.1`);
2. запусти `setup.cmd` (пересоберёт и переустановит поверх);
3. перезапусти Cursor;
4. закоммить изменения в репозиторий.

## Что где

| Путь                          | Назначение |
| ----------------------------- | ---------- |
| `extension/package.json`      | Манифест расширения (contributes: markdown-it плагин, стили, скрипт превью) |
| `extension/extension.js`      | Рендер: YAML-шапка → панель, PlantUML/Mermaid → тёмные диаграммы, TOC → карточка |
| `extension/media/preview.css` | Все стили превью (таблицы, бейджи, чипы, карточки, модалка) |
| `extension/media/preview.js`  | Модальное окно диаграмм: зум колесом, панорама мышью, Esc |
| `build-vsix.ps1`              | Сборка `.vsix` из `extension/` |
| `setup.ps1` / `setup.cmd`     | Установка для члена команды |
| `crossnote/`, `cursor-user/`  | Архив старой схемы на MPE (не используется) |

## Соглашения в документах, от которых зависит вид

- **Панель свойств** — два способа:
  - классическая YAML-шапка первой строкой файла (`---` … `---`);
  - явный блок ```` ```properties ```` (синонимы `props`, `frontmatter`) —
    рендерится панелью из **любого** места документа, порядок не важен.

  Поля плоские `ключ: значение`; массивы `[a, b]` или блочный список `- item`.
  Бейджи: `status` (`unreleased/disabled` серый, `released/enabled` зелёный),
  `stage` (`L1/L2/L3`), `class`, `audience`; прочие поля — текст/чипы с иконкой.
- **Диаграммы** — блоки ```` ```plantuml ```` или ```` ```mermaid ````.
  Тёмная тема накладывается автоматически. Рендер через plantuml.com и kroki.io —
  нужен интернет.
- **Оглавление** — заголовок `## Содержание` (`Оглавление`/`Contents`) + список
  ссылок (маркированный, нумерованный или абзац со `\`-переносами) — станет карточкой.
- **Междокументные ссылки** — `[TEXT](путь/ФАЙЛ.md)` (адрес на `.md`) — чип с иконкой.
- **Инлайн-код** — обратные кавычки для терминов/идентификаторов.
