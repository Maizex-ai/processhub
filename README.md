# .ide-preview — эталон конфигов Markdown-превью

Здесь лежат **эталонные копии** файлов, которые задают внешний вид Markdown-превью
(Markdown Preview Enhanced, MPE) в Cursor: тёмная тема, панель свойств из YAML-шапки,
бейджи полей, оформление таблиц, оглавления, ссылок, диаграмм (Mermaid/PlantUML) и
модальное окно диаграмм с зумом.

Файлы, которыми реально пользуется Cursor/MPE, лежат **в профиле пользователя** и
никак не версионируются — поэтому их легко потерять при сбое/перезапуске. Эта папка —
источник правды под git.

## Для команды: установка в один клик (Windows)

1. Заархивируй папку `.ide-preview` (zip или rar) и передай коллеге.
2. Коллега распаковывает её куда угодно и **двойным кликом запускает `setup.cmd`**.
3. Перезапускает Cursor, открывает `.md`-файл и жмёт `Ctrl+Shift+V`.

Что делает `setup.cmd` (через `setup.ps1`, без возни с политиками PowerShell):
- ставит расширение **Markdown Preview Enhanced** (если в PATH есть `cursor` CLI;
  иначе просит поставить вручную из Extensions);
- кладёт `parser.js` и `style.less` в `%USERPROFILE%\.crossnote`;
- **аккуратно дописывает** нужные ключи MPE в личный `settings.json` (не затирая
  чужие настройки), добавляет `Ctrl+Shift+V`;
- всё, что меняет, предварительно бэкапит (`….bak-<timestamp>`).

Требования у коллеги: установлен Cursor. Расширение MPE поставится само (при наличии
`cursor` CLI) либо ставится вручную один раз.

## Что где

| Эталон (здесь)                     | Реальный путь                                             | Назначение |
| ---------------------------------- | --------------------------------------------------------- | ---------- |
| `crossnote/parser.js`              | `%USERPROFILE%\.crossnote\parser.js`                      | Препроцессор MPE: YAML→панель, «Содержание»→карточка, тёмный PlantUML, модал диаграмм |
| `crossnote/style.less`             | `%USERPROFILE%\.crossnote\style.less`                     | Все стили превью |
| `cursor-user/settings.json`        | `%APPDATA%\Cursor\User\settings.json`                     | Настройки MPE (PlantUML-сервер, тёмный Mermaid, выполнение скриптов и т.д.) |
| `cursor-user/keybindings.json`     | `%APPDATA%\Cursor\User\keybindings.json`                  | `Ctrl+Shift+V` → превью MPE |

## Восстановить после сбоя/на новой машине

```powershell
powershell -ExecutionPolicy Bypass -File .\restore.ps1
```

Скрипт копирует эталон в реальные пути (перед перезаписью делает `.bak-<timestamp>`).
После — перезапусти Cursor или переоткрой превью.

> Внимание: `settings.json` восстанавливается целиком. Если на машине есть другие
> личные настройки Cursor — сначала слей их вручную, а не перезаписывай.

## Зафиксировать свои правки в эталон

Если поправил вид превью (менял живой `parser.js`/`style.less`/настройки) и хочешь
сохранить это в репо:

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1
git add .
git commit -m "preview: update"
```

## Соглашения в документах, от которых зависит вид

- **YAML-шапка**: поля `status` (`unreleased/disabled` серый, `released/enabled` зелёный),
  `stage` (`L1/L2/L3` — градация), `class`, `audience` — рисуются бейджами; прочие поля
  получают дефолтную иконку. Иконки полей настраиваются в `style.less` (`.fm-key--<поле>`).
- **Оглавление**: заголовок `## Содержание` (или `Оглавление`/`Contents`) + список
  markdown-ссылок — превращается в карточку автоматически.
- **Междокументные ссылки**: вид `[TEXT](путь/ФАЙЛ.md)` (адрес на `.md`) — получают
  иконку-чип.
- **Инлайн-код**: обратные кавычки для терминов/идентификаторов.
