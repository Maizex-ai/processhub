# ProcessHub Markdown Preview

Расширение для встроенного превью Markdown в **Cursor** и **VS Code**.
Оформляет документы ProcessHub: панель свойств из YAML-шапки, диаграммы
PlantUML и Mermaid с зумом, карточка оглавления, таблицы, ссылки на документы.
Подстраивается под тёмную и светлую тему редактора.

## Установка Windows

### Cursor

1. Разархивируйте папку `.ide-preview` в любое удобное место.
2. Откройте её и дважды нажмите **`setup.cmd`**.
3. Перезапустите Cursor.
4. Откройте любой `.md`-файл и нажмите `Ctrl+Shift+V`
   (или иконку превью справа вверху вкладки).

Скрипт сам соберёт пакет и установит расширение. Настройки и горячие клавиши
вашего профиля не меняются.

### VS Code

1. Разархивируйте папку `.ide-preview` в любое удобное место.
2. Установите расширение одним из способов:
   - **Если в PATH есть `code`:** дважды нажмите **`setup.cmd`** — скрипт
     поставит расширение и в VS Code.
   - **Вручную:** в VS Code нажмите `Ctrl+Shift+P` → выберите
     **Extensions: Install from VSIX…** → укажите файл
     `processhub.processhub-md-preview.vsix` из этой папки
     (если файла ещё нет — сначала запустите `setup.cmd`, он его соберёт).
     В папке всегда один `.vsix`: новые сборки перезаписывают его.
3. Перезапустите VS Code.
4. Откройте любой `.md`-файл и нажмите `Ctrl+Shift+V`
   (или иконку превью справа вверху вкладки).

## Как пользоваться

После установки откройте любой `.md`-файл. Превью можно вызвать так:

1. **Горячая клавиша** `Ctrl+Shift+V` — превью справа от документа  
   (стандартная клавиша Cursor и VS Code; если занята — см. пункты ниже).
2. **Кнопка в шапке вкладки** — иконка превью справа вверху (встроенная).
3. **ПКМ** по тексту `.md` в редакторе или по файлу в проводнике слева →
   **Open ProcessHub Preview**.
4. **Командная палитра** — `Ctrl+Shift+P` → `Open ProcessHub Preview`
   (или `Markdown: Open Preview to the Side`).

Горячие клавиши расширение **не назначает** — профили пользователей не трогает.

В превью сразу работают наши стили: панель свойств, оглавление, таблицы,
ссылки-чипы, диаграммы.

**Диаграммы (inline):** наведите курсор на карточку — справа сверху кнопки
`+` / `−` / сброс / раскрыть. Колесо мыши — зум, перетаскивание — панорама.
Нижний край карточки можно потянуть и изменить высоту. Кнопка «раскрыть» —
полноэкранная модалка (`Esc` — закрыть).

**Содержание (sidebar):** слева сверху кнопка со списком — открывает / закрывает
плавающую навигацию по заголовкам. В панели есть поиск по словам: в выдаче —
раздел и фрагмент текста с подсветкой. По умолчанию свёрнута. Закрыть —
крестиком или `Esc`.

## Офлайн PlantUML (по желанию)

По умолчанию PlantUML идёт через интернет (plantuml.com). Чтобы не отправлять
диаграммы наружу:

**Вариант A — Java + jar**

1. Установите Java и скачайте [plantuml.jar](https://plantuml.com/download).
2. В настройках редактора:
   - `processhubMdPreview.plantumlRender` → `local`
   - `processhubMdPreview.plantumlJar` → полный путь к `plantuml.jar`
3. Переоткройте превью.

**Вариант B — Docker**

```text
docker run -d -p 8080:8080 plantuml/plantuml-server:jetty
```

В настройках: `processhubMdPreview.plantumlRender` → `docker`.
Переоткройте превью (нужен запущенный контейнер).

## Обновление расширения

1. Поднимите `version` в `extension/package.json` (например `0.5.0` → `0.5.1`).
2. Запустите `setup.cmd` (пересоберёт и переустановит).
3. Перезапустите редактор.
4. Закоммитьте изменения в репозиторий.

| Путь                             | Назначение |
| -------------------------------- | ---------- |
| `extension/package.json`         | Манифест расширения |
| `extension/extension.js`         | Рендер: YAML-шапка, PlantUML/Mermaid, TOC |

## Соглашения в документах

- **Панель свойств** — два способа:
  - классическая YAML-шапка первой строкой файла (`---` … `---`);
  - явный блок ```` ```properties ```` (синонимы `props`, `frontmatter`) —
    из любого места документа.

  Поля: `ключ: значение`; массивы `[a, b]` или блочный список `- item`.
  Бейджи: `status` (`unreleased/disabled` серый, `released/enabled` зелёный),
  `stage` (`L1/L2/L3`), `class`, `audience`; прочие поля — текст/чипы с иконкой.
- **Диаграммы** — блоки ```` ```plantuml ```` или ```` ```mermaid ````.
  Mermaid всегда локально (офлайн). PlantUML — настройка
  `processhubMdPreview.plantumlRender`:
  - `server` (по умолчанию) — HTTP, адрес в `plantumlServer` (plantuml.com);
  - `local` — офлайн: Java + `plantuml.jar` (`plantumlJar` / `java`);
    если пути пустые, подхватываются `plantuml.jar` / `plantuml.java`
    из расширения PlantUML (jebbs);
  - `docker` — локальный контейнер на `http://127.0.0.1:8080`:
    `docker run -d -p 8080:8080 plantuml/plantuml-server:jetty`

  Тема диаграмм по умолчанию тёмная (`diagramTheme`: `dark` / `light` / `auto`).

  Если установлено расширение **PlantUML** (`jebbs.plantuml`), оно тоже пытается
  рисовать блоки `plantuml` во встроенном превью. Наше расширение перехватывает
  эти блоки на себя; для `.md`-превью отдельный PlantUML не обязателен
  (для файлов `.puml` его можно оставить).
- **Оглавление** — заголовок `## Содержание` (`Оглавление`/`Contents`) + список
  ссылок — становится карточкой.
- **Междокументные ссылки** — `[TEXT](путь/ФАЙЛ.md)` — чип с иконкой.
- **Инлайн-код** — обратные кавычки для терминов и идентификаторов.
